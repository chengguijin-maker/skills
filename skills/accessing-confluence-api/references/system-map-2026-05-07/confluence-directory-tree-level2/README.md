# Confluence 空间目录树图谱
生成时间: 2026-05-07

本图谱只遍历目录树, 不抓取页面正文。每个空间从首页开始向下遍历, 最大深度 2, 每个父节点最多 40 个子页面。

## 产物

- confluence-空间目录树总表.csv
- confluence-空间目录摘要.csv
- confluence-空间目录树抓取错误.csv
- 空间-<空间键>-目录树.csv

## 使用方式

先读 confluence-空间目录摘要.csv 判断每个空间的一层目录和主题分布, 再按空间打开对应目录树 CSV 查看父子路径。若某空间存在截断节点, 需要针对该节点继续下钻。
