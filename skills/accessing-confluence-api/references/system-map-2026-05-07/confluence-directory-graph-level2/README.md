# Confluence 目录图谱

生成时间: 2026-05-07

本图谱由二级目录树转换而来, 不包含页面正文。图谱用于先理解 Confluence 各空间内部的内容分布, 再决定是否针对某个空间或目录继续下钻。

## 节点类型

- 空间: Confluence space。
- 目录页面: 空间首页, 一级目录, 二级目录页面。
- 主题: 根据页面标题和目录路径推断出的主题类别。

## 关系类型

- 空间首页: 空间指向其首页页面。
- 包含目录: 父页面指向子页面。
- 推断主题: 目录页面指向主题。
- 覆盖主题: 空间指向主题, 权重为该主题下目录节点数。

## 文件

- confluence-目录图谱节点.csv
- confluence-目录图谱关系.csv
- confluence-空间主题关系.csv
- confluence-空间图谱摘要.csv

## 使用方式

先读 confluence-空间图谱摘要.csv 选择空间, 再用 confluence-目录图谱关系.csv 沿着空间首页和包含目录关系查看结构。需要按主题找空间时, 读 confluence-空间主题关系.csv。
