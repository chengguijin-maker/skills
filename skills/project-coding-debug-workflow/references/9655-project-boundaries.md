# 9655 项目边界

## 1. 主线

当前主线是 9655 内销项目，平台为 MT9655。探索、总结和任务处理都应优先以项目维度组织，而不是只按 JuOS、单个问题或单个工具组织。

## 2. 补充资料边界

| 资料或方向 | 使用方式 |
| --- | --- |
| JuOS | 系统侧补充，可帮助理解构建、CI、系统资料，不替代 9655 内销主线 |
| 深圳研发空间 | 可作为资料来源和背景空间，不等于项目范围 |
| Jira | 问题跟踪、责任、状态、评论和链接佐证，不作为流程事实主源 |
| Confluence | 项目事实、流程、总结、SOP 和技术经验主源 |
| 商显、激光、外销、GTV | 暂不作为主线；可作为可迁移经验参考，必须标注边界 |

## 3. 当前重点阶段

用户当前重点处于编码开发和调试阶段，优先关注：

1. 设备调试。
2. 日志体系。
3. 性能定位。
4. 代码问题。
5. 构建和分支。
6. 自测、Review、合入和测试交接。

## 5. 禁止越界结论

1. 不把 Jira Closed 写成测试、发布或质量闭环。
2. 不把 OTA 台账写成代码分支或构建包证据。
3. 不把 JuOS 构建资料写成 9655 内销构建规则。
4. 不把临时替换 so、remount、overlayfs 修改写成正式修复。
5. 不把参考平台经验写成当前项目事实。
